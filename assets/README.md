# Logo do grupo JMW

Os arquivos fornecidos nesta entrega continham apenas o prompt do projeto. Não havia uma imagem original da logo.

Quando o grupo disponibilizar o arquivo, preserve o original nesta pasta:

```text
assets/logo-jmw-business-division.png
```

No início do README, inclua:

```markdown
![Logo do grupo JMW Business Division 2026](assets/logo-jmw-business-division.png)
```

Para utilizá-la também na página institucional, coloque uma cópia em `public/assets/logo-jmw-business-division.png` e insira a imagem no componente `src/views/Details.jsx` com um texto alternativo adequado. Só acrescente a referência depois que o arquivo existir, para evitar uma imagem quebrada.

O favicon e o ícone de folha são a identidade do MindTrack, criada para a interface, e não uma recriação da logo do grupo.
