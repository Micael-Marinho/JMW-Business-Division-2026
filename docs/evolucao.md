# Registro do incremento

## Edição de 15/10/2026

A aplicação foi organizada em front React/Vite, API Express e PostgreSQL. A estrutura de execução foi simplificada, mantendo o visual, os percursos principais, a identificação acadêmica e o esquema do banco.

Cadastro, login, check-ins, histórico, gráficos, diário, configurações, exportação e exclusão continuam implementados. Esta edição mantém oito testes de regras/cálculos/senhas e quatro de integração da API. Os resultados e limites das verificações estão em `testes.md`.

Não houve pesquisa de usuários, Sprint Review ou retrospectiva com a equipe nesta entrega. Os quadros abaixo servem para registrar essas atividades quando ocorrerem.
