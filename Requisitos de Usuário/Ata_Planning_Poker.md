## 2. Objetivo

Realizar a estimativa de esforço das histórias de usuário do MindTrack utilizando a técnica Planning Poker,
promovendo a colaboração, a discussão sobre a complexidade das funcionalidades e o consenso entre os integrantes.

## 3. Metodologia

A atividade foi conduzida por um facilitador. Para cada história de usuário, os integrantes realizaram estimativas individuais,
revelaram seus votos, discutiram possíveis divergências e definiram um valor final por consenso.

Foi utilizada a sequência de Fibonacci como referência para a atribuição dos Story Points.

## 5. Considerações finais

Após as discussões e validações entre os integrantes, foram definidos os valores finais de Story Points para as nove histórias de usuário.

As estimativas foram registradas no arquivo `HistoriasUsuario.md`, disponível no repositório GitHub do projeto MindTrack.

A atividade foi concluída com a definição consensual dos valores de esforço para as histórias de usuário.
